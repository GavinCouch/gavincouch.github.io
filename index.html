ApolLens

Hackathon team project · Flutter, Dart & ONNX

An offline repair assistant built around the problem of maintaining equipment beyond Earth. The prototype uses a phone camera to identify laptop parts, then provides step-by-step guidance with an on-device language model and spoken instructions.

I built the Flutter app, trained and integrated the component detector, and connected local language models to the repair workflow.

View ApolLens on GitHub
How the prototype works
  • A custom YOLOX-Nano detector recognizes RAM, storage drives, batteries, and cooling fans using ONNX Runtime on the phone.
  • Users confirm the detected parts and describe the problem before following visual and spoken repair steps.
  • Local models use the confirmed components, symptoms, and completed steps to guide the repair. Required models and system voices must be installed before offline use.
  • For supported RAM and storage steps, users can mark numbered screws or clips in a component close-up.
